Detailed Description

Firmware log collection (issue #44): the 0x03xx command group on the LiDAR's log port (56500).

The layouts follow Livox-SDK2 (sdk_core/comm/define.h) and are unverified on hardware (#11). Unrelated to the SDK's own diagnostic logging (log.hpp).
