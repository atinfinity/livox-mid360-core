Detailed Description

Opt-in diagnostic logging (issue #42).

Silent by default: the SDK never writes to the console unless the application installs a handler. Unrelated to the LiDAR firmware log stream (port 56500, 0x03xx commands), see firmware_log.hpp / Device::on_firmware_log (#44).
