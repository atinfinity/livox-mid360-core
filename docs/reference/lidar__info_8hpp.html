Detailed Description

Aggregated read-back types over the keys.hpp codecs (issues #38 / #41): the identity of a LiDAR (serial, product string, firmware versions, MAC), its stored settings and its live status.

Each type has a key list, a decoder that takes any parsed key-value list (an InquireResult or a 0x0102 push) and a one-line to_string with the wire key names, so logs stay greppable. The struct to_string()s of the typed key values live here as well.
