Detailed Description

What the LiDAR needs to know about this host.

Sent as one 0x0100 request (keys 0x0005, 0x0006, 0x0007, 0x0000, 0x001C in that order, then scan_pattern 0x0001 and the present fov keys 0x0015 / 0x0016 / 0x0017 when set) followed, when work_tgt_mode is set, by a second one with 0x001A. Keys not listed here (0x0004 lidar ipcfg, attitude, ...) are left to Session::configure.

std::optional<WorkState> livox::mid360::HostSetup::work_tgt_mode

Target work mode (key 0x001A).

Only kSampling, kIdle and kReady are accepted; anything else → kInvalidArgument with error_key 0x001A. Empty: leave the mode unchanged.
