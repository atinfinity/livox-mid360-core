Detailed Description

Pure-function protocol layer for the Livox Mid-360: framing, parsing and serialisation of control-command frames, point-cloud / IMU data packets and key-value lists.

Reference: "Livox LiDAR Communication Protocol - Mid360", wiki revision v1.4.12 (2026-09-21). Everything is UDP, little-endian. No I/O happens in this header.
