◆ push_timeout

std::chrono::milliseconds livox::mid360::ReconnectOptions::push_timeout {3000}

No accepted 0x0102 push for this long → kDisconnected.

The LiDAR pushes about once per second. A command timeout counts as a disconnect only when the last push is older than a third of this value (one nominal push period).
