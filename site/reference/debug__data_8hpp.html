Detailed Description

Debug raw data collection (issue #93): command 0x0303 switches on a diagnostic stream that Livox support asks for ("debug raw data" in the protocol document, "debug point cloud" in Livox-SDK2).

The stream itself is opaque to this SDK. The request layout follows the protocol document rev v1.4.12; ports and behaviour follow Livox-SDK2 and are unverified on hardware (#106). Unrelated to the firmware log (firmware_log.hpp).
