std::uint64_t livox::mid360::Datagram::recv_time_ns = 0

Host receive time in nanoseconds since the Unix epoch (CLOCK_REALTIME).

On Linux this is the kernel timestamp (SO_TIMESTAMPNS); elsewhere it is sampled in user space right after the receive call.
