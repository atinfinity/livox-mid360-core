Detailed Description

Public API (issue #9): the shared receive side.

The Mid-360 host ports for push (56201), point cloud (56301), IMU (56401) and firmware log (56501, #44) are the same for every LiDAR, so one Context owns those four sockets and the single receive thread, and dispatches datagrams to the registered Devices by source IP. Data path implemented in #6; push parsing is #7. A fifth socket for debug raw data (#93) is opened on request.
