Detailed Description

Host-side install attitude transform (issue #51).

The SDK never applies it by itself: key 0x0012 is stored on the LiDAR and whether the firmware transforms the emitted points is unverified (#11). p' = r * p + t, the livox_ros_driver2 extrinsic convention.
